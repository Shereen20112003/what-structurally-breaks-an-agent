1 Complete Experimental Specification
The primary experiment and follow-on experiment are separately recorded. The primary grid uses N = 8, depths
{1, 2, 4, 8}, candidate counts {2, 4, 8}, active widths {1, 2, 4, 8}, both snapshot endpoints, and both graph families.
Its seeds are 0–255 and each task is evaluated by eight programmed controllers. The follow-on grids use the anchors
in the main-text ablation design; their full per-controller configurations are in results_extended/case_design.
json.
Pairing and randomness. The base generator draws a fixed eight-slot initial array , a permutation of operation
identifiers, a shuffled balanced query assignment, update registers, nonzero increments, and candidate permutations.
Candidate-count levels filter the same eight-code permutation; active-width levels project query and update indices
into the active width. Across work levels, different numbers of operations cause different subsequent random draws,
so seed pairing is not exact surface matching. Hidden resampling uses a separate seeded random stream, draws
eight fresh values after each success, and replaces only active registers. F ailed trials never advance that stream.
Controller sampling uses its own stream. Common controller seeds pair variants, but differing controller logic
can consume different numbers of draws. These choices are intended for reproducibility , not to certify statistical
independence of every repeated condition.
Admission and positive controls. There is no outcome-based rejection or regeneration. All balanced tasks
must query every active register; clustered assignments preserve that coverage and its multiplicities. Concentrated-
query variants explicitly have effective width one and are tagged as a degenerate manipulation. Positive controls
include unrestricted deterministic tracking, residue tracking, deterministic preplanning, unrestricted tracking with
a snapshot after every hidden resampling, and candidate elimination with the worst-case error allowance. The
runner aborts if a designated positive control fails, if the call horizon is exceeded, or if the adaptive cache exceeds
two entries. Analytic probabilities are derived only for supported cases; unsupported predictions are labelled
not_derived, not replaced with a default or fitted estimate.
Adaptive-cache details. Next-use-2 uses the public deterministic ready schedule to prioritize registers queried
in the future. On a visible snapshot, the current query can be answered directly , so future-use selection skips that
operation. During history-only feedback, a successful action confirms the queried residue from the chosen candidate
code. The controller inserts that residue, applies the public increment if relevant, and evicts values whose next use
is furthest away . This is not a generic learned memory strategy; future-query metadata, successful-action feedback,
and public updates are deliberate advantages of the control.
Preparation and storage accounting. Residue caches store values modulo b; raw-value caches store values
modulo eight. Reported value bits exclude dictionary keys, graph metadata, controller code, temporary operands,
and runtime overhead. Preplanning records N candidate slots, using the initial state as preparation workspace;
indexed selection records N maps of b code-to-slot entries. The preparation counter charges Nb table entries for
each of these representations. It is a workload proxy , not a measurement of exact executed CPU instructions or
comparison count in Python’s index function. Lookup counts are kept separate from predicate comparisons. The
experiment does not aggregate these categories into an invented universal compute unit.

2 Calibration Derivations
2.1 Completion states and schedule probabilities
F ork = N/d disjoint chains, a completion set is determined by the completed prefix length 0, . . . , d of each chain,
giving (d+1)k reachable masks. Each chain imposes one internal order on its d operations; interleaving the k orders
gives N!/(d!)k valid permutations. A uniformly sampled operation permutation therefore succeeds with probability
(d!)−k.
F or barriers, all previous layers must be complete before any operation in the next layer succeeds. Each of the
d layers contributes 2k − 1 nonempty partial-completion choices, with one initial empty mask, giving d(2k − 1) + 1
distinct masks. Each layer’s operations can be internally permuted in k! ways, so the valid-order count is (k!)d and
random-order success is (k!)d/N!. F ailed-action sinks are not included in these completion-mask counts.

2.3 Missing-information ceiling
In the hidden-resampling condition, all active values are freshly uniform after each success. Before a masked
decision, conditioning on any visible history still leaves the queried code uniform on0, . . . , b −1. Choosing a different
ready operation cannot change this fact, because every active register has the same independent fresh distribution.
Consequently , the conditional probability of each hidden decision succeeding is at most1/b, regardless of additional
computation.
With no retries, the number of visible decisions on a successful path is v = ⌈N/h⌉ for snapshot period h > 0,
or v = 1 for initial-only feedback. Applying the chain rule gives P(complete) ≤ b−(N−v). An unrestricted exact
controller attains this ceiling. The bound does not apply unchanged to recovery protocols: failed trials preserve
state and provide information that can support elimination. F or scan-limited controllers, formulas that average
visible candidate-order draws are ensemble predictions and are labelled separately from exact instance-conditional
predictions.

5 W orkshop Comparison and Submission Scope
W e inspected four ALA 2025 papers as a purposive sample, not all workshop papers and not a systematic nov-
elty search. Their total PDF lengths are nine pages (failure sampling), ten (Dynamic Thinker), ten (task-graph
scheduling), and eight (deliberation cost). References begin on pages nine, eight, seven, and eight, respectively .
T otal PDF length therefore does not equal the allowed main-text length.
The historical ALA 2025 call allows original work up to eight pages excluding references, and preliminary or
outlook papers up to six pages. It specifies double-blind review and deanonymized camera-ready copies. Our ex-
panded authored version is a preprint-style manuscript with an appendix; the separate review.tex source removes
the author block and appendix, but must still be checked against the current workshop’s track and page rules.
A longer document is not evidence of acceptance or of a stronger contribution. No current-edition acceptance,
conference metadata, or submission date is asserted.

supplied metadata when reproducing that study . The original and follow-on episode files have separate hashes and
execution metadata. The two locally frozen protocols and the time ordering of exploratory analyses are retained
explicitly . Complete primary contrasts, rare-scheduler Wilson intervals, and example traces remain available in the

This artifact contains only programmed-controller evidence. No frontier model, learned policy , training run,
